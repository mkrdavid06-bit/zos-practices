# Лабораторная 2 — fork и сигналы

По заданию «Практическая работа №3»: `fork()`, PID и PPID обоих процессов, `atexit()`, ожидание ребёнка и вывод его кода завершения. Обработчик `SIGINT` установлен через `signal()`, `SIGTERM` — через `sigaction()`.

```sh
make
./fork_demo
```

Ребёнок посылает себе оба сигнала и завершает работу с кодом 7. Родитель выводит этот код и завершается с кодом 0. Обработчик `atexit()` срабатывает в обоих процессах. Порядок сообщений и PID зависят от запуска.
