# Практическая работа 3 Изменение прав доступа

Сборка из этой папки:

```sh
make
```

Нужен компилятор C11. В этой папке находятся все необходимые исходники и общий заголовок.


### Программа mychmod

Все примеры из задания:

```sh
./mychmod +x file.txt
./mychmod u-r file.txt
./mychmod g+rw file.txt
./mychmod ug+rw file.txt
./mychmod uga+rwx file.txt
./mychmod 766 file.txt
```

Права меняются системным вызовом `chmod()`. В числовом режиме каждая восьмеричная цифра задаёт права одной категории: `r = 4`, `w = 2`, `x = 1`. Например, `766` — владелец `rwx`, группа `rw-`, остальные `rw-`.

В символьном режиме используются категории `u` — владелец, `g` — группа, `o` — остальные, `a` — все. Операция `+` добавляет права, `-` убирает, `=` задаёт права. `ug` объединяет владельца и группу; `uga` эквивалентно `a`.

Сначала `stat()` получает текущие права. Затем программа вычисляет новое значение битовыми операциями и передаёт его в `chmod()`. Для нескольких файлов значение вычисляется отдельно, поскольку начальные права могут различаться.

Дополнительно поддержаны:

- Несколько файлов: `./mychmod 640 a.txt b.txt`.
- Несколько правил: `./mychmod u=rw,g=r,o= file.txt`.
- Последовательные операции: `./mychmod u+r-w file.txt`.
- Копирование прав: `./mychmod g=u file.txt`.
- Условное выполнение `X`: добавить выполнение каталогу или файлу, у которого уже есть хотя бы один бит выполнения.
- Специальные биты `s` и `t`, например `u+s`, `g+s`, `o+t`.
- Учёт `umask`, когда категория не указана: `+x` зависит от маски, `a+x` задаёт все три бита выполнения явно.

Перед изменением файлов проверяется корректность режима. Если один файл недоступен, программа сообщает об ошибке и продолжает обрабатывать остальные. Символическая ссылка в аргументе ведёт к изменению прав её целевого файла. Рекурсивного обхода нет.
