# Практическая работа 1 Вывод файлов и поиск строк

Сборка из этой папки:

```sh
make
```

Нужен компилятор C11. В этой папке находятся все необходимые исходники и общий заголовок.


### Программа mycat

Программа последовательно читает файлы и выводит их содержимое в стандартный поток вывода. Без имён файлов читает стандартный ввод. Имя `-` также обозначает стандартный ввод.

| Флаг | Поведение |
| --- | --- |
| `-n` | Нумеровать все строки начиная с 1 |
| `-b` | Нумеровать только непустые строки; имеет приоритет над `-n` |
| `-E` | Перед каждым переводом строки выводить `$` |

Флаги разрешено объединять и ставить после имён файлов. Пустая строка — строка, состоящая только из перевода строки; строка с пробелами считается непустой. Нумерация продолжается между файлами, как в GNU cat. Если файл не заканчивается переводом строки, следующий файл продолжает ту же строку.

Примеры из задания:

```sh
printf 'first\n\nsecond\n' > file.txt
./mycat file.txt
./mycat -n file.txt
./mycat -nE file.txt
./mycat -b -E file.txt
```

Результат `./mycat -nE file.txt`:

```text
     1	first$
     2	$
     3	second$
```

Между номером и содержимым находится символ табуляции. При `-b -E` у пустой строки останется только `$`, без номера.

В реализации `fgetc()` возвращает `int`, чтобы значение `EOF` не смешивалось с байтами файла. Переменная `start` хранит признак начала строки. Номер печатается до первого символа подходящей строки; после `\n` признак устанавливается заново. Ошибка одного файла не мешает обработать остальные.

### Программа mygrep

Первый аргумент после опций — шаблон, остальные — имена файлов. Программа выводит строки, соответствующие шаблону. По умолчанию шаблон — базовое регулярное выражение POSIX, а не просто подстрока. Шаблоны с метасимволами следует заключать в одинарные кавычки.

```sh
./mygrep pattern file.txt
./mygrep '^first' file.txt
./mycat file.txt | ./mygrep first
ls -l | ./mygrep '^d'
```

Поддержаны дополнительные опции перед шаблоном:

| Флаг | Поведение |
| --- | --- |
| `-i` | Игнорировать регистр |
| `-v` | Выбирать несовпадающие строки |
| `-n` | Выводить номера строк |
| `-c` | Выводить количество выбранных строк по каждому файлу |
| `-E` | Использовать расширенные регулярные выражения POSIX |
| `-q` | Не выводить строки и завершиться при первом совпадении |

Примеры: `./mygrep -in 'first' file.txt`, `./mygrep -E 'first|second' file.txt`.

Если файлов нет, `getline()` читает `stdin`. В конвейере оболочка создаёт канал и подключает к нему стандартный ввод `mygrep`. Создавать `pipe()` и запускать bash внутри `mygrep` не требуется. Длина строки не ограничена фиксированным буфером: память расширяется функцией `getline()`.

Регулярное выражение компилируется один раз через `regcomp()`, затем каждая строка проверяется через `regexec()`. Завершающий перевод строки временно исключается из проверки, чтобы якорь `$` обозначал конец содержимого строки. Выбранная последняя строка без `\n` выводится с переводом строки, как у grep.

Коды завершения: `0` — выбрана хотя бы одна строка, `1` — совпадений нет, `2` — ошибка. При `-q` найденное совпадение даёт код `0`, даже если до него встречалась ошибка другого файла.
