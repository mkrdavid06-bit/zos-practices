# Практическая работа 2 Просмотр каталога

Сборка из этой папки:

```sh
make
```

Нужен компилятор C11. В этой папке находятся все необходимые исходники и общий заголовок.


### Программа myls

```sh
./myls -la ../..
./myls -l ../ -a
./myls .. -la
./myls -l -a
```

Все варианты порядка флагов из задания поддержаны. Без пути просматривается текущий каталог. Можно передать несколько файлов и каталогов.

| Флаг | Поведение |
| --- | --- |
| `-a` | Показывать скрытые имена, включая `.` и `..` |
| `-l` | Выводить тип, права, число жёстких ссылок, владельца, группу, размер, время изменения и имя |
| `-la` или `-al` | Включать обе опции |

Имена сортируются через `qsort()` и `strcoll()` с учётом локали. Для воспроизводимого сравнения используйте `LC_ALL=C` и для `myls`, и для системного `ls`.

Каталоги открываются через `opendir()` и читаются через `readdir()`. Сведения об элементах получает `lstat()`: в отличие от `stat()`, она позволяет распознать саму символическую ссылку. Для `-l` цель ссылки считывается через `readlink()`. Имена владельца и группы находятся через `getpwuid()` и `getgrgid()`; если запись не найдена, выводится числовой идентификатор.

Ширины полей вычисляются до печати, поэтому столбцы выровнены. Строка `total` показывает выделенные блоки: на Linux в единицах 1024 байта, на macOS — 512 байт. Размер файла и выделенное дисковое пространство — разные значения.

При выводе в терминал используются ANSI-цвета: каталог — синий, исполняемый обычный файл — зелёный, символическая ссылка — бирюзовая, обычный файл — без выделения. Без `-l` имена размещаются в столбцах по ширине терминала. При перенаправлении или конвейере цвета отключаются, имена идут по одному на строку.

Для проверки вывода на Linux:

```sh
LC_ALL=C ls -la . > /tmp/system_ls.txt
LC_ALL=C ./myls -la . > /tmp/my_ls.txt
diff -u /tmp/system_ls.txt /tmp/my_ls.txt
```
