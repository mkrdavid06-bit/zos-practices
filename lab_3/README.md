# Лабораторная 3 — pipe и FIFO

По заданию «Практическое задание №6»: передача строки с текущим временем и PID отправителя. Получатель выводит своё время и принятую строку.

```sh
make
./pipe_demo
```

`pipe_demo` создаёт ребёнка через `fork()`. Родитель отправляет строку, ребёнок выводит результат после задержки 5 секунд.

Для FIFO запустить две отдельные программы в двух терминалах из одного каталога. Первый терминал:

```sh
./fifo_receiver ./lab_fifo
```

После сообщения `FIFO created` во втором терминале:

```sh
./fifo_sender ./lab_fifo
```

Получатель выводит результат после задержки 10 секунд и удаляет FIFO. Существующий путь не перезаписывается. Если получатель остановлен аварийно, перед повторным запуском удалить оставшийся `lab_fifo`, убедившись, что процессы завершены.

Нужна POSIX-среда (Linux, macOS или WSL). По условию оба варианта следует проверить на сервере кафедры; локальный запуск этого требования не заменяет.
